# 🎮 Game History

> Mapeando a cronologia, enredos e universos das maiores franquias dos videogames.

O **Game History** é um projeto web desenvolvido para organizar as narrativas de jogos aclamados em linhas do tempo interativas. A proposta é permitir que os usuários acompanhem os eventos cruciais de cada franquia em ordem cronológica simples e dinâmica.

---

## Link para a pagina
- ### https://gamehistory.netlify.app

---
## 🕹️ Universos Mapeados

- 🤠 **Red Dead Redemption 2:** O declínio da gangue Van der Linde e a trajetória de Arthur Morgan em 1899.
- 🌿 **The Last of Us Part I & II:** A jornada de sobrevivência, laços e vingança de Joel e Ellie num mundo pós-apocalíptico.
- ⚔️ **The Witcher:** A saga de Geralt de Rívia pelo Continente em busca de Ciri.

---

## 🚀 Funcionalidades

- **Linhas do Tempo Interativas:** Mapeamento cronológico dos principais acontecimentos de cada jogo.
- **Player de Áudio Imersivo:** Músicas de fundo temáticas com controle de play/pause e persistência visual.
- **Mídia Integrada:** Exibição de trailers oficiais via player de vídeo HTML5.
- **Design Responsivo:** Layout adaptado para navegadores desktop e dispositivos móveis (com menu hambúrguer interativo).

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica do conteúdo e elementos de áudio/vídeo.
- **CSS3:** Estilização com variáveis globais, suporte a temas específicos por jogo e layouts flexíveis (Flexbox/Grid).
- **JavaScript (ES6+):** Manipulação da DOM, tratamento de eventos e integração com Web Audio API.
- **FontAwesome:** Ícones vetoriais.
